## 冲突处理

涉及引擎与上层职责，以数据引擎定位规范为准；其余同一 P0 问题，第二部分（18–28 节）覆盖第一部分的通用或可选设计；本页和任务表只作索引。若第二部分自身出现冲突，记录问题并更新权威设计及示例后再实现，不自行选择更宽松的行为。若新增 ADR 或经过评审的正式契约改变设计，应在该变更中同步更新正文与本页，注明生效范围和迁移方式。
