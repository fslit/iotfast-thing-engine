# ADR 0002：数据引擎与上层平台职责边界

状态：基于产品需求的架构边界；接口与实现待验证。

本服务负责设备业务模型、资产与点位、标准数据、实时和历史查询；用户 / 角色 / 菜单、业务授权决策、告警工作流、控制审批和物理设备控制由上层负责。引擎必须验证调用服务身份并执行可信数据范围限制，不能信任客户端自报租户或角色。MCP 与 Agent 为上层适配能力。具体模型和边界见 [数据引擎定位与业务模型规范](../architecture/data-engine-scope.md)。

本决策覆盖 ADR 0001 中关于 MCP 在引擎实施及控制独立分期的解释：两者作为上层或独立服务规划，不是本引擎研发任务。DuckDB 默认目标不因本决策改变；SQLite / MySQL / PostgreSQL 仍为待验证选择。
